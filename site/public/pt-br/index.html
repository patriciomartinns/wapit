Uma WhatsApp Cloud API local para desenvolvimento

O Mailpit do WhatsApp.

Aponte o seu app para o wapit e cada mensagem que ele envia chega numa caixa de entrada com cara de conversa. Cada envio é conferido como a Meta confere, e você responde como o usuário.

$ brew install patriciomartinns/tap/wapit
Ler a documentação Ver no GitHub

Também como imagem de container e com cargo install. macOS, Linux e Windows.

01 · Validação

Falha onde a Meta falha.

Os envios de template são conferidos contra o template salvo. Um envio errado recebe de volta o código de erro da Meta e fica na caixa de entrada, marcado, com o motivo em palavras simples.

  • 132000A quantidade de parâmetros não bate com o template
  • 132001O nome ou o idioma do template não existe
  • 132005Texto longo demais depois de preencher as variáveis
  • 132012O formato do cabeçalho não bate com o template
  • 132015Template pausado, ou desativado (132016)
  • 132018Quebras de linha ou muitos espaços seguidos num parâmetro
  • 131009O índice ou o tipo do botão não bate
  • 131047Mensagem livre fora da janela de 24 horas

02 · Webhooks

Responda como o usuário.

Cada ação na caixa de entrada chega ao seu app como webhook no formato de payload da Meta, assinado com o seu app secret em X-Hub-Signature-256.

messages

Digite ou anexe

Mande texto, imagem ou documento. A primeira mensagem abre a janela de 24 horas.

interactive

Toque num botão

Botões de resposta, respostas rápidas e itens de lista mandam o mesmo payload de um celular de verdade.

statuses

Marque entregue, lida ou falha

Escolha qualquer mensagem do seu app e dispare um status, com falhas usando códigos reais da Meta.

03 · Primeiros passos

Funciona sem configurar nada.

Um binário e um arquivo SQLite local. Rode e ele serve um app padrão. Nunca fala com a Meta, a não ser que você rode wapit sync.

terminal
$ wapit
Graph API mock on 127.0.0.1:8027
Inbox on http://127.0.0.1:8026

$ curl http://127.0.0.1:8027/v23.0/100000000000001/messages \
    -H 'Authorization: Bearer wapit-local-token' \
    -H 'Content-Type: application/json' \
    -d '{"messaging_product":"whatsapp","to":"15550000000",
         "type":"text","text":{"body":"Hello"}}'
