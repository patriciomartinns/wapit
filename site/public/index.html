Mailpit, but for WhatsApp.

Point your app at wapit and every message it sends lands in an inbox that looks like a chat. Each send is checked the way Meta checks it, and you reply as the user.

$ brew install patriciomartinns/tap/wapit
Read the docs View on GitHub

On Windows, download the .zip from the latest release. Also as a container image and with cargo install.

Tap a button. Your app gets the webhook.

Reply, attach a file, tap a button or mark a message read in the inbox. wapit posts the same payload Meta would, signed with your app secret.

Fails where Meta fails.

Template sends are checked against the stored template. A bad send gets Meta's error back, and stays in the inbox flagged, with the reason in plain words.

Works with no config.

One binary and a local SQLite file. Run it and it serves a default app. It never talks to Meta unless you run wapit sync.
