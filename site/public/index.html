A local WhatsApp Cloud API for development

Mailpit, but for WhatsApp.

Point your app at wapit and every message it sends lands in an inbox that looks like a chat. Each send is checked the way Meta checks it, and you reply as the user.

$ brew install patriciomartinns/tap/wapit
Read the docs View on GitHub

Also as a container image and with cargo install. macOS, Linux and Windows.

01 · Validation

Fails where Meta fails.

Template sends are checked against the stored template. A bad send gets Meta's error code back, and stays in the inbox, flagged, with the reason in plain words.

  • 132000Parameter count does not match the template
  • 132001Template name or language does not exist
  • 132005Text too long after the variables are filled in
  • 132012Header format does not match the template
  • 132015Template is paused, or disabled (132016)
  • 132018Line breaks or long runs of spaces in a parameter
  • 131009Button index or type does not match
  • 131047Free-form message outside the 24-hour window

02 · Webhooks

Reply as the user.

Every action in the inbox reaches your app as a webhook in Meta's payload format, signed with your app secret in X-Hub-Signature-256.

messages

Type or attach

Send text, an image or a document. The first message opens the 24-hour window.

interactive

Tap a button

Reply buttons, quick replies and list rows send the same payload a real phone does.

statuses

Mark delivered, read or failed

Pick any of your app's messages and fire a status, failures with real Meta error codes.

03 · Quick start

Works with no config.

One binary and a local SQLite file. Run it and it serves a default app. It never talks to Meta unless you run wapit sync.

terminal
$ wapit
Graph API mock on 127.0.0.1:8027
Inbox on http://127.0.0.1:8026

$ curl http://127.0.0.1:8027/v23.0/100000000000001/messages \
    -H 'Authorization: Bearer wapit-local-token' \
    -H 'Content-Type: application/json' \
    -d '{"messaging_product":"whatsapp","to":"15550000000",
         "type":"text","text":{"body":"Hello"}}'
{"messaging_product":"whatsapp","contacts":[...],"messages":[{"id":"wamid..."}]}
